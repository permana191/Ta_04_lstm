# TA-04: Prediksi Nilai Tukar Mata Uang Asing (Forex) Menggunakan LSTM
Oleh: Sigit Miraj Permana (301240037 / 301240034)
Universitas Bale Bandung

Proyek ini bertujuan untuk memprediksi fluktuasi nilai tukar mata uang (Forex) menggunakan arsitektur deep learning Long Short-Term Memory (LSTM), sebagai pemenuhan Tugas Akhir 04 (TA-04) Pembelajaran Mesin.

## Struktur Direktori
- `dataset/`: Berisi file CSV Foreign Exchange Rates.
- `notebooks/`: Jupyter Notebook untuk Eksplorasi Data (EDA), Pra-pemrosesan, dan Pembuatan Model.
- `models/`: Tempat menyimpan file model LSTM (`.h5` atau `SavedModel`) dan scaler (`.pkl`/`.joblib`).
- `app/`: Source code untuk aplikasi web Flask.
- `docs/`: File laporan proyek (PDF/DOC) dan perancangan tugas.
